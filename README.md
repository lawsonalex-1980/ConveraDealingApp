# FX Hedging Dashboard

Internal dashboard for FX structuring, risk monitoring, and hedging workflows.

## Features
- Live FX spot feed
- FX volatility surface (ATM / RR / BF)
- Integrated tools:
  - ZeroVar
  - Quote Sheet
  - EV Tool
- Role-based workflow (Structuring / Risk / Sales)

## Deployment

### Local
Just open `index.html` in browser

### Netlify
1. Push repo to GitHub
2. Connect to Netlify
3. Deploy (no build required)
